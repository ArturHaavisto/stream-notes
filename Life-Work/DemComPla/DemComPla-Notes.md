# Random features
- Layered information
	- For every information piece, there are summarized, low level information that anyone can understand and then ways to get more detailed information
	- The app would get to learn what the user already knows and suggests the correct level info
- Ways to get summaries/most important information from any amount of time
	- Not just daily/weekly/monthly, but customized and the amount as well.
		- It could be just indexed so that the user can scroll as far as they want
- Extensive comment section that shows already formed opinions/sides clearly for a post
	- There can be different comment views/modes.
		- For example: getting couple of random comments or getting the normal comment section
- Section that shows curated timeline/stack
- A map where the user can easily navigate/browse different areas
- Users are encouraged to connect posts for previous/relevant ones, vote with extensive voting/feedback system, suggest more information
- The idea is to grow information, not rediscover it all the time.
	- When topics don't get new information or changes anymore quickly, there should be ways to kind of randomize or spark up new discussion so that people don't just accept that knowledge.
	- A feature to get a notification when the information/topic has had new developments
- Easy view to see and curate own interests. Multiple algorithms
